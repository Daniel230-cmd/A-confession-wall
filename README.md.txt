# 🕵️ Anonymous Confession Wall

A simple anonymous confession platform built with **PHP, MySQL, HTML, and CSS**.

Users can post confessions anonymously, while an administrator can log in and moderate or delete submissions.

## Features

* Anonymous confession submissions
* MySQL database storage
* Admin login
* CSRF protection
* Password hashing
* Confession moderation and deletion
* Responsive interface

## Technologies

* PHP
* MySQL
* HTML5
* CSS3
* XAMPP

## Running Locally

1. Clone/download the project into:

```text
C:\xampp\htdocs\confession-wall
```

2. Start **Apache** and **MySQL** in XAMPP.

3. Create the `confession_wall` database in MySQL.

4. Open:

```text
http://localhost/confession-wall/
```

## Admin

Admin panel:

```text
http://localhost/confession-wall/admin.php
```
